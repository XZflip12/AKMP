# Музыкальный плейер

Базовый проект для практической работы по реализации связного списка и плейлиста.

## Структура проекта

- `linked_list.py` — основные структуры данных: `Composition`, `LinkedListItem`, `LinkedList`, `PlayList`.
- `music_player/` — модули приложения: модели, логика плейлиста, интерфейс.
- `tests/` — автоматические проверки для основных операций со списком.

## Основной функционал

- создание и удаление плейлистов;
- добавление и удаление композиций;
- изменение порядка треков;
- проигрывание текущей композиции;
- переход к предыдущей и следующей композиции;
- циклическое воспроизведение плейлиста.
